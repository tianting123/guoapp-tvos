# 内置红果站源模块

- **来源**：https://github.com/guoapp-modules/hongguo
- **版本**：1.0.3（2026-11-17）
- **许可**：GPL-3.0-only（见上游仓库的 LICENSE）
- **取用日期**：2026-11-20

这是**官方发布的红果站源模块**，直接内置在安装包里，首启动自动安装。

## 为什么用它，而不是自己实现

红果的取址协议换代极快：2026-10-27、11-02、11-10、11-16 连续改了四次
（端点、参数位置、签名代际、设备档位），每一代都把上一代彻底作废 ——
带旧签名的请求一律回 HTTP 200 + 0 字节的**空体**（软拦截，看不到任何错误码）。

官方模块的好处：

1. **跟站方同步**：官方跟进协议变更，我们跟着更新模块即可，不用重写签名算法。
2. **协议是当前这一代**：v5 签名（X-Helios / X-Medusa / X-SS-STUB），
   站方 11-16 起用，官方 11-17 实机验证通过。
3. **有测试夹具**：官方仓库带 `signing-v5-f13.json` 等黄金向量。

## 本仓为跑这个模块补的能力

官方模块依赖 `host.sm3`（SM3 摘要，v5 签名的 query 哈希要用）。
上游的 JS 模块宿主只提供了 `md5` / `sha256` / `base64` / `utf8` / AES，
**缺 SM3**，所以在 `fork/core/module_sm3.go` 里补了实现，
并通过 `fork/patches/module_host.go.patch` 暴露成 `host.sm3`。

## 其它说明

- 模块里 `main.js` 自带 SM3 实现（JS 版），所以 `host.sm3` 对它不是必需的；
  补上是为了让**其它**需要 SM3 的模块也能用（例如未来可能接入的模块）。
- 官方模块的取址设备档案是 vivo PGT-AN10 / Android 12 / 7.4.3.32 /
  `vivo_8662_64`，取址请求用低端机档位（`device_level: 1`）——
  用中端机档位（3）时部分剧集只返回 H.266 线路，取流直接失败。
